# Phrasing: from Chinese draft to English resume line

## The shape of a good bullet

```
<Past-tense verb> <what you built> <by what means> , <quantified outcome>
```

Examples:

- `Built a Power BI dashboard over 10 listed companies' five-year financials, cutting
  cycle-positioning analysis from two days to four hours.`
- `Integrated DeepSeek APIs and benchmarked three deployment paths on latency, cost and
  compliance, then shipped the on-prem option for sensitive documents.`

If a bullet has no measurable outcome, describe the **decision** you made — a judgement is
still evidence, an adjective is not.

## Verb bank

| Category | Verbs |
|---|---|
| Build | Built, Developed, Implemented, Shipped, Designed, Prototyped, Assembled |
| Analyse | Analyzed, Modeled, Quantified, Benchmarked, Diagnosed, Forecast, Segmented |
| Improve | Reduced, Accelerated, Cut, Automated, Streamlined, Consolidated, Eliminated |
| Deliver | Delivered, Launched, Presented, Authored, Documented, Handed over |
| Lead | Led, Coordinated, Owned, Drove, Mentored, Negotiated |
| Evaluate | Compared, Evaluated, Tested, Validated, Audited, Stress-tested |

Avoid: *Responsible for*, *Participated in*, *Assisted with*, *Helped to*, *Familiar with*
(as a bullet verb), *Learned about*.

## Quantification patterns

| You did | Write |
|---|---|
| Made something faster | `cut <task> from <X> to <Y>` |
| Made something more accurate | `reduced <error> from <X>% to <Y>% on <n> test cases` |
| Made something bigger | `grew <metric> by <X>%` / `from <X> to <Y>` |
| Handled volume | `processed <n> records / <n> questionnaires / <n> documents` |
| Built for others | `used by <n> people / adopted by <n> teams` |
| Chose between options | `benchmarked <A>, <B>, <C> on <criteria>, then selected <X> because <reason>` |
| Found a limit | `established that <X> breaks beyond <threshold>` |

When you genuinely do not have a number, quantify the **scope** instead: number of
companies, records, courses, models compared, pages reviewed, weeks of fieldwork.

## Rewrite examples (real ones from this template's owner)

### 1. Tool user → builder

Before:
> Familiar with AI Agent workflows: skilled at using DeepSeek Harness, Codex and other AI
> Agent tools to assist development and office work, capable of human-AI collaboration.

After:
> Delivered an AI-agent workflow that embedded LLM APIs into research and reporting
> (literature summarisation, code generation, weekly reports, spreadsheet cleaning); built
> three reusable agent templates and cut one literature review from about 4 hours to 40
> minutes.

Why: the first version says *I use AI tools*, which every candidate can say. The second says
*I built a system and here is its effect*.

### 2. Vague quality claim → measured claim

Before:
> … significantly reduced the factual error rate of long-document Q&A.

After (once measured):
> … reducing factual errors on long-document Q&A from X% to Y% across a 50-question
> evaluation set.

Before measuring, write the scope only:
> … with hybrid retrieval and citation tracing to control factual errors in long-document Q&A.

### 3. Course topics → coursework line

Before:
> 主修课程：Python程序设计、云计算、数据结构与算法…

After:
> Relevant coursework: Cloud Computing, Python Programming, Data Structures and Algorithms,
> Database Principles (MySQL), Statistics, Data Mining and Machine Learning.

Keep only courses that support the role you are applying for, and keep the list to one line
if you can.

## Small things that mark a resume as translated

- `Responsible for data cleaning.` → `Cleaned and reconciled master data across three systems.`
- `Familiar with Power BI` → `Built four Power BI dashboards with DAX measures`
- `Good communication skills` → delete; show it in the interview.
- `Various tasks` → name the tasks or cut the sentence.
- British/American spelling: pick one. This template uses American (`analyze`, `summarize`).
- Punctuation: no space before a comma or colon; one space after. Chinese full-width
  punctuation (`，。；：`) must not survive into the English file.
